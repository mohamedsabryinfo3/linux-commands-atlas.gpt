# SOC // LINUX DECK — Linux Systems Knowledge Atlas

مرجع/موسوعة عربية تفاعلية لدراسة Linux Administration وLinux Security على Debian وRocky Linux، مع واجهة مستوحاة من تصميم مرجع المستخدم `linux-commands-atlaszai.vercel.app`: شريط تنقل أفقي، هوية طرفية داكنة، مسار رحلة بصري، ومساران واضحان للأوامر.

## هوية الواجهة وما يميزها

- تصميم Command Deck داكن عالي التباين: Graphite + Neon Lime، مع خطوط Mono للمصطلحات والأوامر.
- هيكل قريب من المرجع: `TRK-01` للحفظ والإتقان، و`TRK-02` للمرجع التشغيلي الذي لا يُطلب حفظه.
- خريطة رحلة تعليمية من Linux Fundamentals إلى الإدارة والشبكات والأتمتة، مع إظهار SOC كمرحلة مستقبلية منفصلة.
- مخططات تعليمية مخصصة داخل الوحدات: طبقات Linux، شجرة الملفات، الصلاحيات، العمليات، الإقلاع، الشبكات، SSH، Firewall، الحزم، LVM، السجلات، Bash والخدمات.
- كل موضوع فرعي يفتح شرحًا، رسمًا بصريًا، ملاحظة Debian × Rocky، أوامر مرتبطة، تجربة VM، ومعيار إتقان.
- مساحة ربط SOC تظهر داخل Accordion مغلق افتراضيًا؛ لا تظهر داخل الشرح الأساسي ولا تدخل في تقدم Linux.

## مسارات الأوامر

1. **TRK-01 — Core Memorization:** 48 أمرًا/نمط استخدام يوميًا يجب فهمها وإتقان كتابتها وتفسير مخرجاتها.
2. **TRK-02 — Advanced Field Reference:** 174 أداة وأمرًا متقدمًا موزعة على 11 مجالًا. هذا مرجع للرجوع عند الحاجة، ولا يُطلب حفظه كله.

## محتوى الموسوعة

- 20 وحدة تعليمية و204 موضوعات فرعية قابلة للفتح، مع رسم/نموذج بصري لكل وحدة.
- 8 معامل عملية متدرجة.
- مقارنة Debian × Rocky في الوحدات التي تختلف فيها الحزم أو أسماء الخدمات أو السياسات أو مسارات السجلات.
- مكتبة قراءة حرة تضم 10 ملفات تعريفية لتوزيعات/منظومات Linux؛ لا تدخل في تقدمك ولا تحتوي على واجبات.
- SOC Connection منفصل ومؤجل، ولا يفتح إلا بعد تأكيد إنهاء Linux وCompTIA Security+.

## ملفات المشروع

- `index.html` — واجهة الموقع والتنقل.
- `styles.css` — نظام التصميم المتجاوب.
- `app.js` — التفاعلات والبحث والرسوم التعليمية وحفظ التقدم.
- `data.js` — بيانات الأوامر والوحدات والمعامل ومكتبة التوزيعات ومسار SOC المؤجل.
- `data.json` — نسخة بيانات قابلة للفحص.
- `CONTENT_MAP.md` — خريطة المحتوى.
- `SOURCES.md` — مراجع تقنية رسمية.
- `previews/` — معاينات فعلية من المتصفح للصفحة الرئيسية، والدرس، ومسار الأوامر، والموبايل.

## النشر على GitHub وVercel

1. فك ضغط المشروع.
2. ارفع **محتويات** مجلد `linux-deck-reference-redesign` إلى جذر مستودع GitHub.
3. اربط المستودع بـVercel.
4. الإعدادات:
   - Framework Preset: `Other`
   - Build Command: فارغ
   - Install Command: فارغ
   - Output Directory: `.`

الموقع static ولا يحتاج قاعدة بيانات أو متغيرات بيئة أو Build Step.

## الحفظ والتقدم

- إتقان الأوامر والوحدات والموضوعات والمعامل وملاحظاتك محفوظ في `localStorage` على المتصفح الحالي.
- زر **تصدير تقدمي** ينشئ نسخة JSON احتياطية.
- الاستيراد يعيد التقدم والملاحظات من ملف JSON.
- لا توجد مزامنة سحابية تلقائية بين الأجهزة.

## تنبيهات فنية

- لا يشغّل الموقع أوامر على جهازك؛ نفّذ الأمثلة داخل Debian/Rocky VM.
- لا تنفذ أوامر تغيير الأقراص أو Firewall أو المستخدمين على نظام إنتاجي دون فهم أثرها وخطة رجوع.
- اسم خدمة SSH غالبًا `ssh` على Debian و`sshd` على Rocky؛ تحقق من النظام الفعلي.
- `/var/log/auth.log` شائع في Debian/Ubuntu، و`/var/log/secure` شائع في Rocky عند استخدام rsyslog. استخدم `journalctl` كذلك.
- Rocky Linux 10 يعتمد NetworkManager؛ لا تعتمد على إعدادات network-scripts القديمة.
- SELinux مهم في Rocky؛ لا تعطّله لتجاوز مشكلة قبل فحص السياق والسياسة ورسائل AVC.
- اختبارات الشبكات تُنفّذ فقط على أنظمة تملك تصريح اختبارها.
