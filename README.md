# LINUX MASTER LAB — Systems Knowledge Atlas

موسوعة عربية تفاعلية لدراسة Linux Administration على Debian وRocky Linux، مع مسارين واضحين للأوامر:

1. **TRACK 01 — Core Memorization:** 48 أمرًا/نمط استخدام يوميًا يجب فهمها وإتقان كتابتها وتفسير مخرجاتها.
2. **TRACK 02 — Advanced Field Reference:** 174 أداة وأمرًا متقدمًا موزعة على 11 مجالًا. هذا مرجع للرجوع عند الحاجة، ولا يُطلب حفظه كله.

## محتويات المشروع

- `index.html` — واجهة الموقع.
- `styles.css` — التصميم المتجاوب.
- `app.js` — التنقل والبحث والمرشحات والتقدم والملاحظات والتصدير والاستيراد.
- `data.js` — بيانات الأوامر والوحدات والـLabs ومراجع SOC.
- `data.json` — نسخة JSON من البيانات.
- `CONTENT_MAP.md` — خريطة الوحدات ومبدأ تصنيف الأوامر.
- `SOURCES.md` — مراجع Debian وRocky وبقية عائلات التوزيعات وGNU Bash.

## الأرقام

- 48 أمرًا ونمط استخدام في مسار الحفظ.
- 174 أداة/أمرًا في المرجع المتقدم، ضمن 11 مجالًا.
- 20 وحدة تعليمية و204 موضوعات فرعية قابلة للفتح، ولكل موضوع micro-lab.
- 8 معامل عملية متدرجة.
- مقارنة عملية مركزة بين Debian وRocky.
- مكتبة قراءة حرة تضم 10 ملفات تعريفية لتوزيعات/منظومات Linux. هذه المكتبة **لا تدخل في تقدمك ولا تحتوي على واجبات أو اختبارات**.
- مساحة SOC منفصلة ومغلقة افتراضيًا، لا تدخل في تقدم Linux.

هذه مجموعة منتقاة لتعلم Linux Administration وتهيئة أساس عملي لمسار SOC، وليست قائمة بكل أمر موجود في منظومة Linux.

## التشغيل المحلي

يمكن فتح `index.html` مباشرة، أو تشغيل خادم محلي:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر على GitHub وVercel

1. فك ضغط المشروع.
2. ارفع محتويات مجلد `linux-systems-atlas` إلى جذر GitHub Repository.
3. اختر Import Git Repository في Vercel.
4. استخدم الإعدادات التالية:
   - Framework Preset: `Other`
   - Build Command: فارغ
   - Install Command: فارغ
   - Output Directory: `.`
5. Deploy.

لا يحتاج الموقع إلى Node.js أو قاعدة بيانات أو متغيرات بيئة أو Build Step.

## مكتبة التوزيعات — قراءة حرة

- افتح `موسوعة التوزيعات` من القائمة الجانبية للتعرف على Debian lineage وRHEL ecosystem وFedora/CentOS Stream وSUSE وArch وAlpine وAmazon Linux وGentoo وNixOS وVoid.
- البطاقات قابلة للفتح والبحث والتصفية، وتعرض مدير الحزم ونموذج الخدمات ودورة الإصدارات والاستخدامات والعلاقة بين المشاريع.
- هذا القسم معرفي اختياري فقط: لا يضيف وحدات، ولا يظهر في عداد الإنجاز، ولا يطلب منك تثبيت أي توزيعة أخرى.

## الحفظ والتقدم

- حفظ إتقان الأوامر، وإكمال الوحدات والموضوعات والـLabs، وملاحظاتك في `localStorage` بالمتصفح الحالي.
- زر **تصدير تقدمي** ينشئ ملف JSON احتياطيًا.
- زر الاستيراد يعيد التقدم والملاحظات من ملف JSON.
- لا توجد مزامنة سحابية تلقائية بين الأجهزة.

## توضيحات تعليمية مهمة

- لا يشغّل الموقع أوامر على جهازك؛ انسخ الأمثلة ونفذها داخل Debian/Rocky VM.
- لا تنفذ أوامر تغيير الأقراص أو firewall أو المستخدمين على نظام إنتاجي دون فهم كامل وأخذ نسخة/خطة رجوع.
- اسم خدمة SSH قد يكون `ssh` في Debian و`sshd` في Rocky؛ تحقق من `systemctl list-unit-files`.
- مسار سجل المصادقة يختلف حسب التوزيعة وإعداد التسجيل: `/var/log/auth.log` شائع في Debian/Ubuntu، و`/var/log/secure` شائع في Rocky عند استخدام rsyslog. استخدم `journalctl` أيضًا.
- Rocky Linux 10 يستخدم NetworkManager وkeyfiles؛ لا تعتمد على `network-scripts` وملفات `ifcfg` القديمة.
- SELinux مهم في Rocky. لا تعطّله لمجرد تجاوز مشكلة؛ افحص السياق والسياسة وسجل AVC.
- أوامر الشبكات والفحص تستخدم فقط على أنظمة وشبكات لديك تصريح باختبارها.
- SOC Connection مخفي/مؤجل ويمكن فتحه يدويًا بعد تأكيد إنهاء Linux وSecurity+.
