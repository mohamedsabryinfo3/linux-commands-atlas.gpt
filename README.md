# Linux Command Atlas

صفحة عربية تفاعلية مستقلة لتعلّم أوامر Linux والرجوع إليها أثناء دراسة Linux وتهيئة المستخدم لمسار SOC.

## التشغيل محليًا
افتح `index.html` مباشرة في المتصفح. لا توجد dependencies أو build step.

## النشر على GitHub وVercel
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. استورد المستودع في Vercel.
3. اختر Framework Preset: `Other`.
4. اترك Build Command وInstall Command فارغين.
5. اجعل Output Directory: `.`.

## أقسام الصفحة
- **أتقن واحفظ الاستخدام:** 42 أمرًا/نمطًا أساسيًا مع أمثلة وعلامات إتقان.
- **مرجع عند الحاجة:** أوامر مساعدة وإدارية وتحليلية لا يلزم حفظها كلها.
- **تطبيقات وسيناريوهات:** أمثلة تجمع أوامر متعددة في مهام Linux قريبة من عمل SOC.

التقدم محفوظ محليًا في المتصفح عبر localStorage. استخدم زر تصدير تقدمي للاحتفاظ بنسخة JSON. لا توجد مزامنة تلقائية بين الأجهزة.

> ملاحظة: الأوامر والخيارات تختلف أحيانًا حسب التوزيعة والإصدار والصلاحيات والحزم المثبتة. راجع `man` والتوثيق الرسمي قبل تنفيذ عمليات إدارية أو تغييرات تخزين/شبكة.
